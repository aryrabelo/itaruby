# Public-corpus declaration — the launch bar, as a versioned file.
#
# The project is benchmarked against Sorbet on four PUBLIC Rails apps
# (rails/rails, mastodon/mastodon, discourse/discourse, gitlab-org/gitlab-foss)
# on both speed and true errors found, and the launch bar is winning on both.
# This file makes that measurement an exit code: scripts/public-gate.sh reads
# one repo per line, clones it when the operator allows, runs
# `ita check <clone> --format=json`, and compares the SORTED diagnostic set
# against the in-clear baseline in scripts/public-baseline/<id>.jsonl
# (normalized: the repo's clone root is stripped from each JSON `path` field
# and replaced with `<id>/`, so the baseline is machine-independent — these
# are PUBLIC repos, so the no-secrecy-wall exception in AGENTS.md applies and
# the diffs are written in the clear).
#
# Format: one repo per line, whitespace-separated:
#   <id> <git-url> <pinned-sha> <dev_ceiling_s>[:<ci_ceiling_s>] [<clone-dir>]
# `<pinned-sha>` is the exact default-branch HEAD these numbers were measured
# against, pinned so a repo rename/rebase cannot silently move the corpus
# under a baseline. Clone the repo into $PUBLIC_CORPORA_ROOT/<id>; a missing
# clone is a SKIP unless PUBLIC_GATE_CLONE=1 clones it (gitlab-foss is
# multi-GB, so the human decides).
#
# `<clone-dir>` is OPTIONAL and defaults to `<id>`. It exists for a RE-PIN:
# the fresh revision is measured in a linked `git worktree` of the canonical
# clone (e.g. rails-head), so the canonical tree that another measurement may
# still be reading does not move under it. When the field is present the gate
# is FAIL-CLOSED over it: the path must exist AND its HEAD must BE
# `<pinned-sha>`, else the repo FAILS — it is not skipped, not repaired by
# PUBLIC_GATE_CLONE=1, and not measured. Without the field the historical
# semantics stand unchanged (a missing or wrong-HEAD canonical clone is a
# SKIP, or a repair under PUBLIC_GATE_CLONE=1).
#
# Ceilings are measured per machine: PUBLIC_COLUMN=dev (default) reads the
# first number; PUBLIC_COLUMN=ci reads the second, never a fallback to dev.
# An absent or malformed selected ceiling FAILS. Each measured ceiling is
# anchored wall time x1.5, rounded up — slack is debt (AGENTS.md, binding).
#
# Pins, all from `git ls-remote <url> HEAD`:
#   2026-09-02  rails 3df2cbea2027026a29edb92cbb7e336a63e35444
#               mastodon 171438e185139efd68df7245f39f57c880dceff6

#   2026-09-19  rails 6610cb45b39b6a2c1f260f90bbe920b5899f844b
#               mastodon 2c92a56e5d0fb490cc2e49a0dd9652499000fcb4
#               discourse eff621544daf344ce70e470b7f54f27bc75b68d9
# The 2026-09-19 re-pin moved each corpus ~2.5 weeks forward after the

# new revision in the same commit (scripts/public-baseline/README.md records

#
